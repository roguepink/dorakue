# ゆうしゃの たいれつ

レトロRPG風の **縦スクロール・シューティング**。
勇者ひとりで旅立ち、章を進めるごとに戦士・魔法使い・僧侶が仲間に加わって隊列を組みます。
オート攻撃で魔物を倒しながら「じゅもんコマンド」で戦況をひっくり返し、10の章の先にいる魔王を討つ短時間プレイのゲームです。

- `index.html` 1ファイルで完結（ライブラリ不要・インストール不要）
- BGM・効果音はすべて Web Audio でその場で生成するオリジナル曲
- PC（キーボード）とスマホ（ドラッグ／タップ）の両方に対応

## 遊び方

| 操作 | PC | スマホ |
|---|---|---|
| 移動 | 方向キー / WASD（Shift で低速） | 画面をドラッグ |
| 攻撃 | オート | オート |
| じゅもん | X / Enter / Z | 右下の「じゅもん」ボタン |
| 武器切替 | C / Tab | 右下の武器ボタン |
| 音量 ON/OFF | M | 右上の ♪ |
| ポーズ | P | ― |

- 仲間が倒れると **ひつぎ** になって隊列の後ろについてきます。僧侶が生きていれば蘇生の呪文で生き返ることがあります。
- 魔物を倒すと MP が少しずつたまります。じゅもんメニューを開くと時間がゆっくりになるので、落ち着いて選べます。
- 勇者の武器は3種類（けん＝前方に広がる連続斬り／ゆみ＝敵を貫通する速射／ブーメラン＝往復して多段ヒット）。それぞれ「ぶき アップ」のドロップで★5まで強化でき、ボタンでいつでも持ち替えられます。
- 戦士はときどき必殺「かいてんぎり」（広範囲・大ダメージ）、僧侶はときどき「キュア」で少し回復、倒れた仲間には「リヴァイブ」。
- 魔法使いの追尾弾は「まほうのしょ」のドロップで★5まで強化（弾数・威力・連射が上昇）。
- ドロップ：くすりそう（回復）／まほうのみず（MP）／たからばこ（G … たまにミミッカ）／ぶき アップ／まほうのしょ
- 進行は章の始まりに自動セーブされ、タイトルの「つづきから」で再開できます。スマホの「戻る」ボタンを押しても終了せず、中断メニューが出ます。
- ゲームオーバー後にレベルが引き継がれるような成長要素はありません。毎回まっさらな状態で遊ぶアーケード型です。

## じゅもん

| じゅもん | MP | 使い手 | 効果 |
|---|---|---|---|
| フレア | 6 | まほうつかい | 敵を追尾する爆炎の玉 ×3（着弾で範囲爆発） |
| ブレイズ | 10 | まほうつかい | 横一列の炎の壁が画面上へ走り、触れた敵すべてにダメージ |
| フロスト | 12 | まほうつかい | 敵全体を氷漬けにして動きと弾を止める |
| ヒーリア | 14 | そうりょ | 光の柱とともに仲間全員の HP を全回復 |
| エクスプロ | 20 | まほうつかい | 衝撃波と連続爆発で画面全体に大ダメージ＋敵弾消去 |

## 公開方法（GitHub Pages）

`https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます。
