# ゆうしゃの たいれつ

レトロRPG風の **縦スクロール・シューティング**。
勇者ひとりで旅立ち、章を進めるごとに戦士・魔法使い・僧侶が仲間に加わって隊列を組みます。
オート攻撃で魔物を倒しながら「じゅもんコマンド」で戦況をひっくり返し、10の章の先にいる魔王を討つ短時間プレイのゲームです。
魔王を倒すと「うらのせかい」が始まり、血と闇に染まった凶暴な魔物たちが待つ裏10章に突入します。

- `index.html` 1ファイルで完結（ライブラリ不要・インストール不要）
- BGM・効果音はすべて Web Audio でその場で生成するオリジナル曲
- PC（キーボード）とスマホ（ドラッグ／タップ）の両方に対応

## 遊び方

| 操作 | PC | スマホ |
|---|---|---|
| 移動 | 方向キー / WASD（Shift で低速） | 画面をドラッグ |
| 攻撃 | オート | オート |
| じゅもん | X / Enter / Z | 右下の「じゅもん」ボタン |
| 武器切替 | C / Tab | 右下の武器ボタン |
| 音量 ON/OFF | M | 右上の ♪ |
| ポーズ | P | ― |

- 仲間が倒れると **ひつぎ** になって隊列の後ろについてきます。僧侶が生きていれば蘇生の呪文で生き返ることがあります。
- 魔物を倒すと MP が少しずつたまります（おもては最大30）。じゅもんメニューを開くと時間がゆっくりになるので、落ち着いて選べます。
- 勇者の武器は3種類（けん＝前方に広がる連続斬り／ゆみ＝敵を貫通する速射／ブーメラン＝遠くの敵まで追いかける誘導弾）。それぞれ「ぶき アップ」のドロップで★5まで強化でき、ボタンでいつでも持ち替えられます。
- 戦士はときどき必殺「かいてんぎり」（広範囲・大ダメージ）、僧侶はときどき「キュア」で少し回復、倒れた仲間には「リヴァイブ」。
- 魔法使いの追尾弾は「まほうのしょ」のドロップで★5まで強化（弾数・威力・連射が上昇）。まほうのしょは魔法使いが加入してから出現します。
- ドロップ：くすりそう（回復）／まほうのみず（MP）／たからばこ（G … たまにミミッカ）／ぶき アップ／まほうのしょ
- 倒れた仲間は、その章をクリアすれば次の章の始まりに全員生き返ります（全章共通）。
- 進行は章の始まりに自動セーブされ、タイトルの「つづきから」で再開できます。スマホの「戻る」ボタンを押しても終了せず、中断メニューが出ます。
- ゲームオーバー後にレベルが引き継がれるような成長要素はありません。毎回まっさらな状態で遊ぶアーケード型です。

### うらのせかい（裏11〜20章）
表の10章をクリアすると自動的に始まります。一度うらのせかいに入ると、次回からタイトルで「おもてから はじめる」「うらから はじめる」を選べます（うらからは仲間4人そろった状態で始まります）。舞台・ボスは表と対応していますが、魔物は「くさったプルン」「おんりょう」「しにがみコヅチ」のように腐敗・流血した姿に変わり、HP・弾ダメージ・出現数がさらに上昇。ボスも「くさりゆくキングプルン」「くびなしのきし」「しんのまおうゾルガ」など牙と血の目を持つ悪夢の姿で、HP は表の1.6〜2.7倍。専用のBGMと赤い霧・灰の降る背景になります。裏ではブーメランの威力が2倍になり、戦士の必殺技が「いなずまぎり」（画面全体に稲妻が走り、敵の弾をすべて消して雑魚を全滅、ボスにも大ダメージ）に変わり、MP の上限は 50 から始まり、裏の章を1つクリアするごとに 5 ずつ増えます（最大95）。
各ボスは2段階制で、1段目を倒すと「○○・かくせい」（大型化・HP×1.6・攻撃速度アップ）が現れます。
ボスは固有の攻撃に加えて、弾の壁／らせん弾／うねる弾／十字弾／連続射撃／手下召喚のうち3種をローテーションで使います。
