# ゆうしゃの たいれつ

レトロRPG風の **縦スクロール・シューティング**。
勇者・戦士・魔法使い・僧侶の4人が一列になって進み、オート攻撃で魔物を倒しながら
「じゅもんコマンド」で戦況をひっくり返し、3つの章の先にいる魔王を討つ短時間プレイのゲームです。

- `index.html` 1ファイルで完結（ライブラリ不要・インストール不要）
- BGM・効果音はすべて Web Audio でその場で生成するオリジナル曲
- PC（キーボード）とスマホ（ドラッグ／タップ）の両方に対応

## 遊び方

| 操作 | PC | スマホ |
|---|---|---|
| 移動 | 方向キー / WASD（Shift で低速） | 画面をドラッグ |
| 攻撃 | オート | オート |
| じゅもん | X / Enter / Z | 右下の「じゅもん」ボタン |
| 音量 ON/OFF | M | 右上の ♪ |
| ポーズ | P | ― |

- 仲間が倒れると **ひつぎ** になって隊列の後ろについてきます。僧侶が生きていれば蘇生の呪文で生き返ることがあります。
- 魔物を倒すと MP が少しずつたまります。じゅもんメニューを開くと時間がゆっくりになるので、落ち着いて選べます。
- ドロップ：くすりそう（回復）／まほうのみず（MP）／たからばこ（G … たまにミミッカ）／武器（攻撃力アップ、3段階）
- ゲームオーバー後にレベルが引き継がれるような成長要素はありません。毎回まっさらな状態で遊ぶアーケード型です。

## じゅもん

| じゅもん | MP | 使い手 | 効果 |
|---|---|---|---|
| メラム | 6 | まほうつかい | 近くの敵を追尾する火球 ×3 |
| ベギラム | 10 | まほうつかい | 横一列の炎が画面上へ走り、触れた敵すべてにダメージ |
| ヒャダルク | 12 | まほうつかい | 敵全体を凍らせて動きと弾を止める |
| ベホマリー | 14 | そうりょ | 仲間全員の HP を全回復 |
| イオナズム | 20 | まほうつかい | 画面全体に大ダメージ＋敵弾消去 |

## 公開方法（GitHub Pages）

`https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます。
